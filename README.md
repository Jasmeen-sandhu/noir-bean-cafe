# Noir & Bean Café ☕

A modern, responsive café website with online menu browsing and a working client-side cart and checkout experience.

## Features

- Premium responsive café design
- Specialty coffee, tea, food and dessert menu
- Category filtering
- Shopping cart with quantity controls
- LocalStorage cart persistence
- Checkout form and order confirmation
- Contact form
- Mobile-friendly layout
- No build tools required

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

This project is a static website and can be deployed directly with GitHub Pages. In the repository, go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
